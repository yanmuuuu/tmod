首页高级Models3D

Models3D

Models3D 将 .obj / .gltf 资产导入为 Vault3DModel，通过 Model3DRenderer（一个 RenderHandle）按层绘制到游戏画面，支持蒙皮动画。服务端 Main.dedServ 下加载返回 Vault3DModel.Empty，不会创建 GPU 资源。

客户端GPU 专用
Weight=5PRT 之后绘制
LayerModel3DLayer

概述

Section titled “概述”

Models3D 适合 Boss 装饰、载具、武器模型、环境 3D 物件等客户端视觉。

适合：

  • glTF 蒙皮动画的角色 / Boss 模型
  • 贴地或悬浮的 3D 装饰（NPC / 弹幕 PostDraw）
  • 需要与物块 / 玩家排序的 3D 内容（Model3DLayer）

不适合：

  • 服务端逻辑或碰撞判定：使用 NPC / Projectile / Actor
  • 纯 2D 精灵特效：使用 PRT
  • 复杂后处理全屏管线：自定义 RenderHandle（见 RenderHandle）

临时绘制 vs 常驻实例

Section titled “临时绘制 vs 常驻实例”
临时（Draw / Submit）常驻（RegisterPersistent）
生命周期仅当前帧直到 UnregisterPersistent
典型场景弹幕尾迹、一次性特效NPC 身上持续存在的模型
更新方式每帧传参或构造新实例修改 Model3DInstance 字段
性能适合低频、短生命周期适合长期存在、每帧改变换

快速开始

Section titled “快速开始”

路径可省略扩展名，按 .obj → .gltf 顺序探测。详见 VaultLoaden。

挂载到 NPC 工作流

Section titled “挂载到 NPC 工作流”

持久 3D 装饰遵循注册 → 更新 → 注销。玩法逻辑留在 NPC 上；Models3D 仅负责客户端绘制。

步骤操作
1用 [VaultLoaden] 自动加载 .gltf / .obj 到静态 Vault3DModel 字段
2在 ModNPC.OnSpawn(IEntitySource source) 中用 model.IsValid 守卫（服务端得到 Empty）
3创建 Model3DInstance，设置 Layer、Scale、可选 AnimationPlayer
4每次生成调用一次 Model3DRenderer.RegisterPersistent(_instance)
5每帧 AI() 中赋值 _instance.Position = NPC.Center，旋转取自 NPC.rotation
6阶段切换时用 AnimationPlayer.Play("attack", fadeIn: 0.2f) 交叉淡入
7死亡或 despawn 时在 OnKill 调用 Model3DRenderer.UnregisterPersistent(_instance)
8按需求选择 Model3DLayer，使模型与物块/玩家正确排序
9不要在 Main.dedServ 上从 3D 实例读取碰撞或阶段
10客户端测试：OBJ 常需 CullBackface = false；加载失败查 model.Diagnostic

要点：

  • 绘制前检查 model.IsValid
  • Position 使用世界像素坐标（框架自动减 screenPosition）
  • OBJ 模型常设 CullBackface = false

架构

Section titled “架构”
flowchart LR
    VL[VaultLoaden / 手动 Load] --> Model[Vault3DModel]
    Model --> Inst[Model3DInstance]
    Inst -->|Submit 临时| Renderer[Model3DRenderer]
    Inst -->|RegisterPersistent| Renderer
    Renderer -->|extends| RH[RenderHandle]
    RH -->|Weight=5| Pipeline[PRT 之后的绘制管线]
    Pipeline --> Screen[合成到游戏画面]
组件说明
Vault3DModel静态模型资源（网格分组、材质、骨架、动画 Clip）
Model3DInstance单次绘制描述（位置、旋转、缩放、层级、Effect 等）
Model3DRenderer渲染器（RenderHandle），按 Model3DLayer 分层绘制
Model3DLoadenHandleVaultLoaden 加载器
AnimationPlayer实例级动画播放头（蒙皮 / cross-fade）
ObjModelLoader / GltfModelLoader手动加载入口

RenderHandle 管线

Section titled “RenderHandle 管线”

Model3DRenderer 继承 RenderHandle，由框架在多个 Terraria 绘制阶段挂载。Weight = 5，排在 PRT（更低 weight）之后，避免覆盖粒子画布状态。

原子 API（DrawInstance、DrawMeshGroup、BuildWorldMatrix 等）可在自定义 RenderHandle 中复用加载与矩阵基础设施。全屏后处理、Weight 排序与 SpriteBatch 契约详见 RenderHandle。

常见问题

Section titled “常见问题”
问题原因 / 处理
模型不显示IsValid 为 false；检查路径、日志、Diagnostic
专用服务器空模型预期行为；服务端返回 Empty，客户端才加载 GPU
忘记 UnregisterPersistent实体销毁后模型仍绘制；在 Kill / OnKill 注销
OBJ 模型缺面设 CullBackface = false
动画不动未设 Animation；或 Clip 名不匹配 TryGetClip
自定义 shader 全黑非 BasicEffect 需在 ConfigureEffect 自行传参
与 PRT 绘制顺序错乱Models3D Weight=5 在 PRT 之后；勿在 PRT 回调里改全局 RenderState 而不恢复
CastShadow 无效前向兼容预留，当前管线尚未实现阴影

警告

Models3D 为客户端 / GPU 专用。在 Main.dedServ 或专用服务器上不要依赖 3D 模型做玩法判定；逻辑应放在 NPC / Projectile / Actor 等服务端可见实体上。
